MangaCraft サポート

MangaCraftは、物語のアイデアをマンガにするiPhone・iPad用アプリです。台本を書き、登場人物を配役し（写真1枚であなた自身も出演できます）、すべてのコマを描いて吹き出しにセリフを入れます。できあがった作品は、読んだり、書き出したり、共有したりできます。

お問い合わせ

MangaCraftは個人開発者が作っています。使い方のご質問、アカウントやプライバシーに関するご相談など、お問い合わせは mangacraft.support@gmail.com までメールでお送りください。

いちばん簡単なのはアプリから送る方法です。設定 → 問題を報告 を開くと、アプリのバージョンと端末の情報が書き込まれた状態でメールが作成されます。

絵や肖像の問題を報告する

アプリが描いた絵を報告するには：

  • コマを開いて「この絵を報告」をタップする（描かれたすべてのコマにあります）
  • 設定 → 問題を報告 を開く

どちらも mangacraft.support@gmail.com 宛てのメールが開きます。絵のどこに問題があるかを書いてください。「この絵を報告」から開いたメールには、作品とコマがすでに書き込まれています。

あなたの肖像が許可なく使われていると思われる場合も、同じ方法でお知らせいただければ対応します。アプリをお使いでない場合は、mangacraft.support@gmail.com へ直接メールしてください。

MangaCraftで作ってよいもの、いけないものはコンテンツルールにまとめています。

アカウントを削除する

  1. MangaCraftで設定を開きます（ライブラリ上部の歯車）。
  2. アカウントの「アカウントを削除」をタップします。
  3. 「アカウントを削除」で確定します。

アカウントとクレジット残高・履歴が当社のサーバーから削除され、MangaCraftのAppleでサインインのアクセス権が取り消されて、Apple IDからMangaCraftの連携が解除されます。残っていたクレジットも一緒に削除されます。作品はこの端末に残ります。

アカウントを削除しても、サブスクリプションは解約されません。サブスクリプションはAppleが請求しているため、Apple IDの設定で解約しないと更新が続きます（iPhone・iPadでは 設定 → 自分の名前 → サブスクリプション → MangaCraft）。App Storeのサブスクリプション画面を直接開くこともできます。

端末の作品も消すには、MangaCraftの 設定 → すべて削除 を使います。この端末からすべての作品と画像を削除します。元に戻せません。

購入を復元する

クレジットとサブスクリプションはアカウントに保存されているので、新しいiPhoneやiPadでは、まず同じApple IDでサインインしてください。そのあと：

  1. 設定 → クレジットを購入 を開きます。
  2. 購入画面の上にある「復元」をタップします。

購入画面はどこから開いても同じ「復元」ボタンがあります。設定のサブスクリプション欄にある「購入を復元」でも同じことができます。

作品はこの方法では戻りません。作品はサーバーではなく端末に保存されているためです。端末を替える前に 設定 → すべての作品をバックアップ でファイルを保存しておき、新しい端末で 設定 → バックアップを読み込む を使ってください。

クレジットのしくみ

クレジットは何に使いますか？

絵を描くときです。文章でできたものはずっと無料。物語、登場人物、台本を書くのにクレジットはかかりません。

描くのに何クレジットかかりますか？
内容クレジット
完成したコマ1つ6
設定画1枚（初回）無料
場所1つ（初回）無料
設定画や場所の描き直し6
各コマの最初の2回の描き直し無料
アプリの一貫性チェックによる描き直し無料
汗の滴を取り除く自動修正無料

生成に失敗した場合、使われたクレジットは自動で返却されます。

クレジットはどうやって手に入れますか？

新しいアカウントには無料クレジットが60付きます。そのあとは、スタジオプランに登録するか、クレジットパックを購入してください。

クレジットに有効期限はありますか？

ありません。クレジットに期限はありません。換金や譲渡はできません。

なぜサインインが必要なのですか？

クレジットはアカウントに保存されるので、新しいiPhoneにも引き継がれます。サインインにはAppleでサインインを使うため、Apple IDのパスワードを私たちが見ることはありません。

クレジットの使いみちを確認するには？

設定 → クレジット → 使用履歴 で、追加・使用されたクレジットをすべて確認できます。

サブスクリプションを解約するには？

Apple IDの設定から行います。サブスクリプションは、期間終了の24時間前までに解約しない限り自動更新されます。詳しくはサブスクリプションの規約をご覧ください。

返金

購入はすべてAppleを通じて行われ、返金もAppleが対応します。reportaproblem.apple.com にApple IDでサインインし、該当する購入を選んで問題を伝えてください。支払い情報を私たちが見ることはないため、こちらで返金することはできません。

描画に失敗した場合は、お問い合わせいただかなくてもクレジットは自動で返却されます。
